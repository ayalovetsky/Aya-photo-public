# Фоторедактор АЯ

Фоторедактор, который работает прямо в браузере телефона и ставится на экран «Домой» как приложение.

- Фильтры, экспозиция, контраст, света/тени, насыщенность, баланс белого (пипетка, авто, пресеты)
- Кадрирование, поворот, выпрямление горизонта
- Ластик: нейросеть MI-GAN (работает на устройстве, через onnxruntime-web) и быстрый режим
- Фото никуда не отправляются — вся обработка на телефоне

**Установка на iPhone:** открыть ссылку в Safari → «Поделиться» → «На экран „Домой“».
**Android:** открыть в Chrome → меню → «Установить приложение».
